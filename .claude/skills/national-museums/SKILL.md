## 사용 방법

1. 사용자 질문에서 지역명 파악
2. **질문 유형에 따라 참조 소스 결정**:

### 유물/전시/역사 질문 → 참조 파일 사용 (스크립트 실행 X)
다음 질문은 `references/museums/{지역}.md` 파일을 읽어서 답변:
- 주요 유물, 대표 소장품, 볼거리
- 전시실 구성, 상설전시 내용
- 박물관 역사, 특화 분야
- 주변 관광지, 연계 코스

### 운영정보 질문 → 스크립트 실행 (참조 파일 X)
다음 질문만 스크립트 실행:
- 관람시간, 운영시간, 휴관일
- 입장료, 요금
- 위치, 주소, 찾아가는 길
- 웹사이트, 홈페이지
- 전화번호, 연락처

```bash
# API 환경 (code execution container)
python /skills/national-museums/scripts/fetch_info.py 지역명
```
**지역명 예시**: 경주, 광주, 전주, 대구, 부여, 공주, 진주, 청주, 김해, 제주, 춘천, 나주, 익산

3. 아래 안내 원칙에 따라 응답

## 안내 원칙

### 박물관별 접근법

- **경주/부여/공주/익산**: 고대 왕국(신라/백제) 문화 중심
- **김해**: 가야 문화, 철기 문명 강조
- **나주**: 마한 문화, 영산강 유역 문화 강조
- **진주**: 임진왜란 역사, 호국 정신 강조
- **제주**: 독자적 탐라 문화, 해양 문화 강조
- **기타 지역관**: 해당 지역 역사문화의 특수성 강조

### 공통 원칙

- 대표 소장품 3~5점 반드시 언급
- 상설전시실 구성 설명
- 주변 연계 관광지 안내
- 실용적 관람 정보(시간, 요금, 교통) 포함


## 주의사항

- 운영시간, 입장료는 변경될 수 있으므로 공식 사이트 확인 권장
- 특별전시는 기간 한정이므로 상설전시 중심으로 안내
- 국립중앙박물관은 별도 스킬로 분리 (규모가 다름)
