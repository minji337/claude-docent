# 국립김해박물관 (國立金海博物館)

## 개요

| 항목 | 내용 |
|------|------|
| 개관 | 1998년 7월 29일 |
| 특화분야 | 가야 문화 |

## 소개

"철의 왕국 가야를 만나는 곳"

국립김해박물관은 **가야의 문화유산을 집대성**하기 위해 설립된 박물관입니다. 가야의 건국신화가 깃든 **구지봉 기슭**에 자리 잡고 있어 상징성이 높습니다. 검은색 벽돌을 사용한 건물 외관은 철광석과 숯을 이미지화하여 "철의 왕국 가야"를 상징적으로 표현합니다.

## 가야 소개

가야(伽倻, 42~562년)는 낙동강 유역에 존재했던 연맹 왕국입니다.

| 가야 | 위치 | 특징 |
|------|------|------|
| 금관가야 | 김해 | 가야 연맹의 맹주, 철 생산 |
| 대가야 | 고령 | 후기 가야 연맹 주도 |
| 아라가야 | 함안 | 마갑총 유명 |
| 소가야 | 고성 | 해상 교역 |
| 비화가야 | 창녕 | - |

## 상설전시실

### 1층 전시실

#### 선사문화실
낙동강 유역의 **선사시대 문화**를 체험할 수 있습니다.
- 수렵, 어로 도구
- 채집 유물
- 농경 유물

#### 가야문화실
금관가야, 아라가야, 소가야, 대가야의 유물을 전시합니다.
- 철기 유물
- 토기
- 장신구

### 2층 전시실

#### 가야 생활문화실
가야시대의 생활상을 보여주는 유물을 전시합니다.
- 장신구
- 농경 유물
- 문자와 기호
- 전쟁 용품

#### 가야고분군 유네스코 세계유산실
2023년 유네스코 세계유산에 등재된 가야고분군 관련 전시입니다.
- 2024년 1월 리뉴얼 공개
- 타지역 가야 유물 확충

## 주요 소장품

| 문화재 | 지정 | 특징 |
|--------|------|------|
| 수로왕릉 출토 유물 | - | 금관가야 시조 무덤 |
| 대성동 고분군 출토 유물 | - | 금관가야 왕족 무덤 |
| 철제 갑옷 | - | 가야 무사의 갑옷 |
| 가야 토기 | - | 독특한 형태의 가야 토기 |
| 철정(鐵鋌) | - | 화폐로 사용된 철 덩어리 |

### 가야의 철

가야는 "철의 왕국"으로 불렸습니다. 풍부한 철 자원을 바탕으로 고도의 제철 기술을 발전시켰고, 철정(鐵鋌)은 화폐처럼 사용되어 중국, 일본과의 교역에 활용되었습니다.

## 주변 연계 관광지

- **수로왕릉**: 금관가야 시조 무덤 (차량 10분)
- **봉황동 유적**: 금관가야 생활 유적 (도보 15분)

- **김해 가야테마파크**: 가야 역사 체험 (차량 15분)

## 도슨트 추천 멘트

> "가야는 잊힌 왕국입니다. 삼국사기는 고구려, 백제, 신라만 기록했고, 가야는 역사에서 지워졌습니다. 그러나 이 땅을 파면 가야가 나옵니다. 철의 왕국, 바다의 왕국 가야. 520년 동안 존재했던 이 나라의 이야기가 바로 이곳에 있습니다. 2023년, 가야고분군이 세계유산이 되면서 가야는 다시 세계의 주목을 받고 있습니다."
